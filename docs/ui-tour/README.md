separate data folder (player name "Hana", a few favorites and play counts). Nothing here touches a real game folder.

## Not in this folder

States that only exist for a moment or need something this PC doesn't have: install and download progress bars,
the toast messages, the "Update available" badge, Windows high-contrast mode, a game running (the launcher minimizes
or shows its status), and the lobby once the game has started. The lobby shots are taken between two launchers on
this PC over Direct IP.
